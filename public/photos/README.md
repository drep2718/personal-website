# Photos

Drop image files in this folder and they render automatically in the gallery
at `/secret/photos`.

- Supported: `.jpg` `.jpeg` `.png` `.webp` `.gif` `.avif` `.svg`
- They're ordered newest-name first, so a filename like `2026-07-26-sunset.jpg`
  sorts to the top. The filename (spaces from `-`/`_`) shows as the caption.
- Commit and push — the new photos appear after deploy.

The `sample-*.svg` files here are placeholders to show the layout. Delete them
once you add real photos.
